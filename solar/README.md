# ひだまりシミュレータ

都道府県、年間電力使用量、太陽光・蓄電池の条件から、30年間の累積支出と損益分岐点を概算する静的Webアプリです。

## 起動

`solar/index.html` をブラウザで開くか、リポジトリ直下で次を実行します。

```sh
python3 -m http.server 8000
```

その後 `http://localhost:8000/solar/` を開きます。

## 特徴

- 太陽光なし／太陽光パネルのみ／太陽光パネル＋蓄電池の比較
- 47都道府県の地域別発電原単位による概算
- 太陽光・蓄電池の「おまかせ」入力
- パネル劣化、FIT単価、電気料金上昇、機器交換を考慮
- 損益分岐点の線形補間
- SNS共有用PNGの生成
- X・Threads向け投稿文（`#ななふしの家` を含む）

計算結果は概算です。実際の導入判断では、設置場所の日射条件や見積もりを用いた専門事業者の試算も確認してください。
